An array object provides **attributes** that enable you to discover information about its atructure and contents. In this section well use the following arrays:

```python
import numpy as np

integers = np.array([[1,2,3],[4,5,6]])

# Output:
#array([[1,2,3],
#       [4,5,6]])

floats = np.array([0.1,0.2,0.3])
#Output:
#array([0.1,0.2,0.3])

```
NumPy does not display trailing 0s to the right of the decimal point in floating-point values.

## Determining an arrays Element Type

The array function determines an arrays element type form its arguments elements.
You can check the element type with an arrays dtype atribute:

```python
integers.dtype
#Output:
#dtype("int64") int32 on some platforms 

floats.dtype
#Output:
#dtype("float64")
```

## Determining  an arrrays Dimensions

The attribute **ndim** contains an arrays number of dimensions and the attribute **shape** contains a tuple specifying an arrays dimensions:

```python
integers.ndim
#Output:
#2

floats.ndim
#Output:
#1

integers.shape
#Output:
#(2,3)

floats.shape
#Output
#(5,)
```

Here, integers has 2 row and 3 columns (6 elements) and floats  is one-dimensional, so the output of floats shows a one-element tuple (indicated by the comma) containing floats number of elements (5).

## Determining an arrays Number of Elements and Element Size

You can view an arrays total number of elements with the attribute **size** and the number of bytes required to store each element with **itemsize**:

```python
integers.size
#Output:
#6

integers.itemsize # 4 if C compiler uses 32-bit ints
#Output: 
#8

floats.size
#Output: 
#5

floats.itemsize
#Output: 
#8

```
Note that integers size is the product of the shape tuples values two rows of three elements each for a total of six elements. In each  case, itemsize is 8 beacuse integers contains int64 values and floats contains float64 values, which each occupy 8 bytes.
