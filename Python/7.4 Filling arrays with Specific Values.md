NumPy prrovides functions **zeros, ones** and **full** for creating arrays containing 0s, 1s or a specific value, respectively. By default, zeros and ones create arrays containing float64 values. we'll show how to customize the element type momentairly. The first argument to these functions must be an integer or a tuple of integers specifying the desired dimensions. For an integer, each function returns a one -dimensional array with the specified number of elements.

```python
import numpy as np

np.zeros(5)

#Output:
# array([0,0,0,0,0])

```

For a tuple of integers, these functions returns a multidimensional array with the specified dimensions. You can specify the array's element type with the zeros and ones function's dtype keyword arguments:

```python
np.onces((2,4),dtype=int)

#Output:
# array([[1,1,1,1
#         1,1,1,1 ]])

```

The arrays returned by full contains elements with the second argument's value and type:

```python
np.full((2,4),13)

#Output:
# array([[13,13,13,13
#         13,13,13,13 ]])

```
